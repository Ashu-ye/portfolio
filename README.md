# Portfolio

- index.html: page structure
- css/style.css: all styling and animations
- js/data.js: ALL your content (text, projects, skills, certs, links). Edit this most often.
- js/splash.js: intro splash animation
- js/main.js: builds the page from data.js and runs the animations
- assets/: put your resume PDF here
Open index.html in a browser to preview. Host the whole folder on GitHub Pages or Netlify.
